# Berkas Font Resmi Dies Natalis ke-44 SMAN 1 Gedeg

Direktori ini menyediakan seluruh berkas font asli dalam format **TrueType (.ttf)** dan **OpenType (.otf)** untuk identitas visual Dies Natalis ke-44 SMA Negeri 1 Gedeg (1982—2026).

Semua font dilisensikan di bawah **SIL Open Font License (OFL)** sehingga 100% gratis, bebas, dan legal digunakan untuk kebutuhan publikasi sekolah, media sosial, seragam, percetakan spanduk, maupun cendera mata resmi.

---

## Struktur Direktori Font

```
assets/fonts/
├── plus-jakarta-sans/         # Font Utama Korporat & Media Sosial
│   ├── ttf/                   # Format TrueType (Regular, Medium, SemiBold, Bold, ExtraBold, Italic)
│   └── otf/                   # Format OpenType (Cetak Presisi Tinggi)
│
├── cinzel/                    # Font Seremonial & Klasik Akademik
│   ├── Cinzel-Variable.ttf    # Font Variable Modern (Semua Bobot 400—900)
│   └── ttf/                   # Format Static TTF (Regular, Bold, Black, Decorative)
│
└── playfair-display/          # Font Tajuk Pementasan Seni & Tema AVERSA
    └── ttf/                   # Format TrueType Variable (Roman & Italic)
```

## 3 Keluarga Huruf Resmi & Penerapannya

| Nama Font | Format Berkas | Peruntukan Utama | Aturan Penulisan |
| :--- | :--- | :--- | :--- |
| **Plus Jakarta Sans** | TTF & OTF | Teks isi surat, proposal, poster media sosial, keterangan acara, dan teks website. | *Sentence case* atau *Title Case*. Leading 1,4—1,6×. |
| **Cinzel** | TTF | Piagam penghargaan, sertifikat, tiket emas (*golden ticket*), nama resmi almamater, dan plakat. | **Wajib Huruf Kapital Penuh (ALL CAPS)** dengan spasi antarhuruf renggang (*tracking* +100 s.d. +200). |
| **Playfair Display** | TTF | Tajuk pementasan seni, festival budaya, dekorasi panggung, dan tajuk kreatif tema AVERSA. | Digunakan selektif sebagai *Display Headline* panggung. |

## Panduan Pasangan Huruf (*Font Pairing Guide*)

1. **Format Formal & Kedinasan (Piagam, Kop Surat, Sertifikat)**:
   * Judul / Nama Lembaga: **Cinzel Bold** (ALL CAPS, tracking renggang)
   * Isi Teks / Penjelasan: **Plus Jakarta Sans Regular**
2. **Format Publikasi & Media Sosial (Feed Instagram, Banner, Poster)**:
   * Judul Acara: **Plus Jakarta Sans ExtraBold**
   * Sub-kategori: **Plus Jakarta Sans SemiBold**
   * Waktu & Lokasi: **Plus Jakarta Sans Regular**
3. **Format Pentas Seni & Festival Kreatif**:
   * Tajuk Panggung: **Playfair Display / AVERSA**
   * Keterangan Detail: **Plus Jakarta Sans Medium / SemiBold**

## Cara Memasang Font (*Installation*)

### Pada Sistem Operasi Windows:
1. Buka folder font yang diinginkan (misalnya `assets/fonts/plus-jakarta-sans/ttf/`).
2. Pilih seluruh berkas `.ttf`, klik kanan, lalu pilih **Install** (atau **Install for all users**).
3. Buka aplikasi desain Anda (CorelDraw, Adobe Photoshop, Illustrator, atau Microsoft Word). Font akan langsung muncul di daftar font.

### Pada Sistem Operasi macOS:
1. Buka folder font yang diinginkan.
2. Klik ganda pada berkas `.ttf` atau `.otf`, lalu klik tombol **Install Font** pada jendela Font Book yang terbuka.
3. Font siap digunakan di seluruh aplikasi sistem.
